Privacy & local storage details

This PWA is intentionally self-contained. It has no analytics scripts, advertising code, sign-in system, remote API calls, or cloud database.

  • Tracker data is stored in IndexedDB on this device.
  • Receipt photos are compressed locally before being stored in IndexedDB.
  • The service worker only caches the app’s own static files so the app can open offline.
  • Export creates a backup file only when you press Export data. You decide where that file goes.
  • Clearing website/app data or deleting the web app can remove local records, so periodic backups are recommended.
